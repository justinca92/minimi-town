# Minimi Town

**Your Steam Deck library as a little street.** Every game is a storefront, and a baby penguin walks along the street to whichever one you pick. Press Ⓐ and it waddles to the door, turns around and goes in, and the game's page opens. Come back and it steps out of the same door.

## Features

- **A street instead of a row of tiles.** Each game gets its own building (same building every time), with the game's art on its screen.
- **The name is on the shop.** Each storefront's sign carries the game's name; in Neon Rain City a little square blade sign shows the game's icon in neon.
- **Buildings tell you what's going on.** Recently played (lights on, OPEN sign, a plant by the door), new (balloons and a NEW tag), not installed (shutter and CLOSED sign), downloading (scaffolding with a progress banner), not played for months (dust and cobwebs).
- **Playtime tiers.** 100 h+ *Regular*, 200 h+ *Landmark* and 500 h+ *Legend* storefronts get fancier: gold trim and flower boxes, string lights, flags and searchlights, then a golden dome and a red carpet. Each theme has its own version.
- **Two themes.** *Minimi Town*, a sunny street whose sky follows the clock, and *Neon Rain City*, always a rainy night, with wet-street reflections, neon signs and CRT storefront screens.
- **A penguin with moods.** It follows you along the street, sprints if you rush, trips sometimes, and arrives out of breath. Poke it, fling it into a wall, or pet it with the touchscreen. Bother it too much and it sulks in an alley until you cheer it up.

## Controls (home)

| Input | Action |
|---|---|
| D-pad ◀ ▶ | Move along the street |
| Ⓐ | The penguin goes in and the game's page opens (Play / Install are there) |
| L2 | Search, like ▲ on the stock home (R2 there: back to the street; Ⓑ there: Steam's menu, the search box stays) |
| R2 | What's New / Friends / Recommended (Steam's own sections), sliding in from the right |
| L2 there (or swipe right) | Back to the street |
| Ⓑ there | To the top of the sections; at the top, Steam's menu (like the stock home) |
| ≡ | Steam's game menu (Play, Properties, …) |
| Ⓨ | Shake the street |
| Touchscreen | Swipe to move, double-tap to play, grab / poke / pet the penguin |

D-pad ▲ ▼ do nothing on the street. Settings live in Quick Access (…) → Minimi Town: home toggle, theme, sky, which games, sort, sounds, haptics and language.

## Install (Decky developer mode)

Minimi Town isn't in the Decky store.

1. Install [Decky Loader](https://decky.xyz).
2. Quick Access (…) → Decky → ⚙️ → **General** → turn on **Developer mode**.
3. **Developer** tab → **Install Plugin from URL** (the `minimi-town-x.y.z.zip` link from the latest release) or **Install Plugin from ZIP**.

If you also use Spindeck, turn off its "Use the wheel as Home" so the two don't both replace the home screen.

## Uninstalling leaves nothing behind

Minimi Town never changes Steam's settings, controller layouts or files. Turning the home toggle off shows Steam's own home; disabling or uninstalling the plugin restores everything immediately, and uninstalling deletes its settings file (which is also where the penguin's mood is kept).
